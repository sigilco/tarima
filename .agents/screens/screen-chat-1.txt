The eve agent panel inside the workspace shell. Closed, it is a floating
clay bubble in the bottom-right of the content column. Open, it is a
fixed-height card docked bottom-right inside the ChatPanelSlot area:
header (session title, a compact session switcher dropdown with recent
session ids and a "new session" action, and a close button), a message
list (AI Elements Conversation + Message), tool-call chips (AI Elements
Tool) inline in the assistant turn that made them, an approval block (AI
Elements Confirmation) when the turn asks the person, and the composer
(AI Elements PromptInput) pinned at the bottom.

Transport: useEveAgent from "eve/react" against the same-origin nitro
proxy at /eve/*, which forwards to the in-process eve runtime loopback
origin with the caller's tarima_session cookie. Streaming is live. The
project id from /app/w/$projectId reaches the agent as clientContext on
every send so the tools scope to that project; on /app (no project) the
panel sends no project scope and the empty state says so.

States: chat-closed | chat-open-empty | chat-streaming | chat-with-tools
| chat-error | chat-approval
Transitions: bubble click opens the panel; (×) closes to the bubble; the
composer send → chat-streaming; a turn that calls tools → chat-with-tools;
a failed send → chat-error, Retry re-sends the same text; an open
interaction with kind approval → chat-approval, answering settles it; the
session switcher swaps the session id (remounts the hook), "new session"
calls newSession().
