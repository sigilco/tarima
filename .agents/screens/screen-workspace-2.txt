The content area of the workspace shell at /app: a compact table of the
signed-in organizer's projects from GET /api/ui/projects (via the
fetchProjectsFn server function, session cookie forwarded). Each row shows
the project name, its approval-flow stage (contract projectStageSchema,
absent on old rows → "—") and the creation date. "New project" opens an
inline create row (name + optional brief is NOT part of this screen — the
minimal POST /api/ui/projects { name } path only; SP7 replaces the old
brief-first form). Clicking a row navigates to /app/w/$projectId. The old
board remains reachable at /app/p/$projectId until SP7.
