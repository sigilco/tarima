The persistent chrome of the new workspace. A Notion-like collapsible
sidebar on the off-white #FAFAFA surface sits left of a content area that
renders the active view (projects list or project view). The chip tabs
switch the sidebar's own listing mode; Documents and Audit are stubs until
later boxes land them. The bottom user block shows the signed-in email
(from /api/ui/settings session resolution; the api does not expose a name
yet, so the email stands in) and a sign-out button that clears the session
cookie client-side and lands on /login. An empty bottom-right container is
reserved for the eve chat panel (SP4) via <ChatPanelSlot/>; the shell does
not implement chat.
