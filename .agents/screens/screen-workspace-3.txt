One project inside the workspace shell (workspace-1 chrome stays mounted).
The header shows the project name and its stage badge; the loader pulls the
project from GET /api/ui/projects/:projectId and the entities from
GET /api/ui/projects/:projectId/entities. Entities render as a read-only
table (name, contact or "—", status, missing deliverables, last activity) —
editing stays on the old board at /app/p/$projectId until SP7; a link in
the header offers it. Below the table sits the <ChatPanelSlot/> reserved
container for the eve agent (SP4). No tasks/up-next section exists in the
api yet; the missing-deliverables column serves that role.
