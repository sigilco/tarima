# Tarima

Working documents for the venue-platform project: a venue-pays B2B availability/visibility platform for independent restaurants, cafés, and bars — dead weeknight hours booked by recurring event organisers, agent-led event management end to end. Built toward a YC W27 application (deadline Nov 2, 2026) with a dual-city POC (SF + Málaga, Oct 6–24).

## Docs

Start at [`docs/00_README.md`](docs/00_README.md) — the master index. Key files:

- `docs/01_scope.md` — product scope: pivot B (venue-pays visibility) as the product, pivot A (organiser-pays booking) as the wedge
- `docs/05_poc_plan_v2.md` — the dual-city POC plan (payment-free, behavioral kill criteria)
- `docs/07_pivot_variants.md` — A/B/C as standalone tracks
- `docs/08_payment_free_poc.md` — how to validate WTP without holding customer money
- `docs/event_market_data_pack.html` — interactive SF + Málaga event-market data pack (open in browser)
- `research/` — foundation memo + YC/alternative-program research

## Version history

Documents evolve through git — the latest version is always on `main`; every prior delivery version is a commit. History: foundation research → POC draft + agent prompts → v1 delivery → venue-pays direction update → payment-free POC update. See `git log`.
