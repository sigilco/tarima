# SF venue hit-list input — independent cafés/bars/restaurants for off-peak event hosting
Compiled 2026-10-04. Confidence: `informed` (venue knowledge + corpus evidence) — these are *candidates for outreach*, not measured data. Venues marked ✅ already host recurring events in this month's data.

## Recommended neighborhoods

**#1 Mission (Valencia/16th–24th corridor).** #1 neighborhood across community sources: 18.6% of Meetup SF events (137), 16.6% of Eventbrite sample, 25% of Mon–Thu evening events. Densest independent F&B strip in the city, already hosting book clubs, language tables, trivia, mahjong.

**#2 Hayes Valley / Divisadero corridor.** Smaller count but the right economics: 19 Meetup + 6 Luma + 24 Eventbrite events in-window, high indie-venue density, central location, venues already taking organiser bookings (Rick & Roxy's hosts founder networking; The Function runs weekly comedy). 

*Alternate:* Marina/Cow Hollow (35 Meetup events — strong social/founder mix, dense Chestnut/Union indie stock) if Hayes walk-ins go cold. Avoid FiDi/SoMa for the walk-in track despite volume: corporate venues, lunch-rush economics, chains.

## Outreach framing for walk-ins (from the data)

- Pitch the numbers: "On a dead Tuesday 18–21h there are ~60 listed events running in SF, a third of them in bars — the Mission carries a quarter of them."
- Min-spend beats rent: the corpus shows organisers default to bars already; the ask is a *stated* Mon–Thu window + house terms, not a new behavior.
- Lead with the prepaid group: "15–30 guests who buy F&B, booked by us; organiser pays the fee, not you."
